# 异动提醒周期配置设计

## 目标

将异动提醒当前固定的 2 分钟统计周期开放为按秒配置，同时保留现有阈值配置和默认行为。

## 配置

- 新增 `estock.priceAlertWindowSeconds`，类型为整数，默认值为 `120`，最小值为 `1`。
- 用户可以填写任意整秒，例如 `11`、`30` 或 `90`，不要求是特定数值的倍数。
- `estock.priceAlertThresholdPercent` 保持不变，默认值为 `1`，最小值为 `0.1`。
- 旧配置没有新字段时继续使用 120 秒周期，无需迁移。
- 运行时遇到非有限数值、小于 1 或非整数时，周期回退为 120 秒。

## 行为

- 价格追踪器使用配置的秒数换算为毫秒，计算该时间窗口内的价格波动。
- 悬浮提示使用实际生效的周期，例如“异动提醒：11 秒内股价波动 +1.20%。”。
- README 和 Changelog 说明周期及阈值均可配置。

## 验证

- 测试默认 120 秒周期。
- 测试 11 秒周期可以触发异动提醒，并在悬浮提示中显示 11 秒。
- 测试非法周期回退为 120 秒。
- 运行完整测试、TypeScript 编译和 VSIX 打包，包内版本保持 `0.9.5`。
