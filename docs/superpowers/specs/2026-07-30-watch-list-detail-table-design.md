# 股票池详情表格设计

## 目标

新增命令 `estock: 查看股票池股票详情`。执行后不弹出股票选择框，直接刷新股票池并在 Output Channel 中以纯文本表格展示全部股票详情。

## 交互

- 命令 ID 为 `estock.showWatchListDetail`。
- 命令标题为 `estock: 查看股票池股票详情`。
- 输出复用现有 `码盯·撸得金` Output Channel。
- 表格按照股票池中的配置顺序展示，每行对应一只股票。
- 股票池为空时提示用户先添加关注股票。
- 全部行情获取失败时提示用户刷新或检查股票池。
- 部分行情获取失败时仍展示成功结果，并在表格下方列出未获取到行情的股票代码。

## 表格字段

表格完整保留单只股票详情中的字段：

1. 名称。
2. 代码。
3. 当前价。
4. 涨跌。
5. 涨跌幅。
6. 今开。
7. 最高。
8. 最低。
9. 振幅。
10. PE。
11. PB。
12. 股息率。
13. 成交量。
14. 更新时间。
15. 雪球详情。

缺失字段统一展示为 `--`。延迟行情在更新时间后追加 `（延迟约15分钟）`。

## 格式化规则

- 沪深场内基金的当前价、涨跌额、今开、最高和最低继续使用三位小数。
- 其他 A 股和港股的价格字段继续使用两位小数。
- 涨跌幅、振幅、PE、PB 和股息率使用两位小数。
- 涨跌额与涨跌幅为正数时保留 `+` 前缀。
- 成交量使用现有本地化千分位格式。
- 雪球详情使用现有 `toXueqiuUrl()` 生成。

## 表格布局

输出使用等宽纯文本表格。实现按各列内容动态计算列宽，并在计算时将中文等宽字符视为两个显示宽度，以保持中英文内容对齐。每列之间使用固定分隔符，保留完整雪球链接，不截断字段。

## 代码结构

- `StockService` 新增 `showWatchListDetail()`，负责刷新股票池、收集行情、处理空数据和输出表格。
- 新增局部、纯函数式的表格格式化逻辑，负责把 `Quote` 转为字段并生成表格文本。
- `extension.ts` 注册新命令。
- `package.json` 增加激活事件和命令声明。
- `README.md` 补充新命令说明。

- 验证完整字段、正负号、ETF 三位价格精度和普通股票两位精度。
- 验证缺失字段输出 `--`。
- 验证部分行情失败时仍输出成功结果并列出失败代码。

## 非目标

- 不修改现有单只股票详情命令。
- 不新增 Webview 或配置项。
- 不修改行情 Provider、股票池配置格式或刷新策略。
